# Oferta founders (model A — lokalnie, BYOK)

Dokument **marketingowy / produktowy**, nie umowa. Cenę, VAT i warunki prawne ustal z księgowością i prawnikiem (`docs/LEGAL_PRIORITIES_FOR_COUNSEL.md`).

## Co kupujesz

- Prawo do używania dostarczonej **wersji binarnej / pakietu** aplikacji Architekt Wolności (Tauri + wskazówki do backendu) zgodnie z licencją, którą dostajesz przy zakupie.
- **Bring your own key:** koszt modeli LLM ponosisz u dostawcy API (Anthropic); sprzedawca nie hostuje Twoich debat ani briefów.

## Czego nie ma w cenie

- Hostingu chmurowego, SLA uptime, wsparcia 24/7.
- Klucza API Anthropic ani limitów po stronie sprzedawcy.
- Gwarancji zgodności z każdą polityką IT Twojej organizacji (testuj przed zakupem).

## Wsparcie

- Kanał wskazany przy zakupie (np. e-mail), tryb **best effort**, zakres: instalacja według `INSTALL.md`, błędy regresji w dostarczonej wersji — nie custom development.
- Szablony odpowiedzi: [`docs/SUPPORT_PLAYBOOK.md`](SUPPORT_PLAYBOOK.md).

## Prywatność (uproszczenie)

Dane debat zapisujesz **lokalnie** (SQLite); operator treści briefów przy normalnym użyciu lokalnym to **Ty**. Jeśli sprzedawca zbiera jakąkolwiek telemetrię, musi to być **osobno** opisane i wyłączone domyślnie — tu: załóż brak telemetrii, dopóki nie wdrożono inaczej w produkcie.
