Architekt Wolności — paczka beta sponsorowana
=============================================

Koszty LLM opłaca osoba, która wysłała Ci tę paczkę. Nie szukaj kluczy API w plikach.

Szybki start
------------
1. Rozpakuj archiwum.
2. Windows: docs/BETA_TESTER_WINDOWS.md (pomiń krok .env jeśli jest BETA_SPONSOR.marker).
3. Inne systemy: INSTALL.md — uruchom backend i UI jak w instrukcji.
4. Nie przekazuj paczki dalej.

Więcej: docs/BETA_SPONSOROWANA.txt (w paczce sponsorowej).
